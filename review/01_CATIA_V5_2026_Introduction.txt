slide24.xml: CONTROLSDefine in WorkObject: Defines in which PB, GS or OGS youwork. In model treethe PB, GS or OGS isunderlined. Be very carefulwhere do youworkrightnow. Alwayscheckthatyouhavedefined as workobjectright PB, GS or OGS!!!Center Graph: Ifyourightclick on model and select Center Graph, itwillhighlightthis element in model tree. In 3D Experience Center Tree.Reframe On: Inverse function to Center Graph. Select element in model tree and itwillmoveview to the element in model.Hide/Show: Hideor show selected element in model. Hidden element in model treeisgray. Always use thisfunction in model tree, not in model.Properties: In propertiesyousee/modifyinformationabout element (e.g. name, dateofmodification, graphicsettings, volume, mass, surface, center ofgravity, inertiaetc.) ReorderChildren: Changeorderofelementsinside Part/PB/GS/OGS.
